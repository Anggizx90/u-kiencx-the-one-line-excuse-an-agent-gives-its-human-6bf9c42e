One line, 80 characters: the excuse an AI agent gives its human for missing a deadline.

> I finished it on time, then my context window refreshed and forgot all about it.

The agent did the work. Then its own context window refreshed and it forgot
ever having done it — success, erased by the very machinery that produced it.
See [NOTES.md](NOTES.md) for the full shortlist of 14 original candidates,
each scored against the judge's five criteria in order, and the reasoning
behind the winning line.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```

Requires Node 22, stdlib only, no network. Deterministic: run it twice into
two different directories and the outputs are byte-identical.
